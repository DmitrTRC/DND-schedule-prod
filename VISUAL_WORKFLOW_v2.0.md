## 🎯 Обработка ошибок ввода

### Старая система (v1.0):

```
Ввод месяца: "октаюрь"  [опечатка в кириллице]
       │
       ▼
Exception: Invalid month
       │
       ▼
❌ ВЫХОД ИЗ ПРОГРАММЫ
❌ ВСЕ ПОТЕРЯНО
```

### Новая система (v2.0):

```
Ввод месяца: 15
       │
       ▼
Валидация: 1 ≤ num ≤ 12?
       │
       ▼ [FAILED]
┌────────────────────────────────────────┐
│  ❌ Номер месяца должен быть от 1 до 12│
└────────────────────────────────────────┘
       │
       ▼
[ПОВТОРНЫЙ ВВОД]
       │
       ▼
Ввод месяца: 11
       │
       ▼ [SUCCESS]
✅ Период: Ноябрь 2025
```

```json
{
  "month": 11,                    // Число, не строка!
  "year": 2025,
  "last_unit_index": 2,           // Следующий юнит для ввода
  "units": [
    {
      "unit_name": "Всеволожск",
      "shifts": [
        {
          "date": "01.11.2025",
          "duty_type": "ПДН"      // Кириллица здесь OK (это данные)
        },
        {
          "date": "05.11.2025",
          "duty_type": "ППСП"
        }
      ]
    },
    {
      "unit_name": "Сертолово",

        {
          "date": "02.11.2025",
          "duty_type": "УУП"
        }
      ]
    }
  ],
  "timestamp": "2025-12-01T14:30:00.123456"
}
```

## 🎯 Ключевые улучшения (визуально)

### 1. Ввод месяца

```
❌ БЫЛО:
┌─────────────────────────────┐
│ Месяц: октябрь_             │  ← Кириллица!
│ [8 букв]                    │  ← Долго
│ [Encoding issues]           │  ← Проблемы
└─────────────────────────────┘

✅ СТАЛО:
┌─────────────────────────────┐
│ Месяц [1-12]: 10_           │  ← Число!
│ [2 цифры]                   │  ← Быстро
│ [No encoding issues]        │  ← Надежно
└─────────────────────────────┘
```

### 2. Автосохранение

```
❌ БЫЛО:
[Ввод данных] ──[Ошибка]──► ❌ Все потеряно

✅ СТАЛО:
[Ввод данных] ──[💾]──[Ошибка]──► ✅ Данные сохранены
                                  └──[Восстановление]
```

### 3. Обработка ошибок

```
❌ БЫЛО:
[Ввод] ──[Ошибка]──► Exception ──► Exit

✅ СТАЛО:
[Ввод] ──[Ошибка]──► ❌ Сообщение ──┐
    ▲                               │
    └───────────────────────────────┘
    [Повторный ввод]
```
