## ✅ Тест 1: Создание графика с числовым вводом месяца

### Шаги:

1. Запустите приложение
2. Выберите `1 - Создать новый график`
3. Введите месяц **числом** (например: `11`)
4. Введите год (по умолчанию текущий)
5. Для первого юнита добавьте 2-3 смены:
   - День: `1` → Тип: `1` (ПДН)
   - День: `5` → Тип: `2` (ППСП)
   - День: `10` → Тип: `3` или Enter (УУП)
6. Завершите ввод: Enter (пустой ввод)

### Ожидаемый результат:

```
✓ Период: Ноябрь 2025
✓ Добавлено смен: 3
💾 Автосохранение: 1/8 юнитов
```

### ✅ Проверить:

- [ ] Месяц принимает только числа 1-12
- [ ] Некорректные числа (0, 13) отклоняются с ошибкой
- [ ] Дефолт = текущий месяц
- [ ] Никаких encoding errors!

## ✅ Тест 2: Обработка некорректного ввода

### Шаги:

1. При вводе месяца:
   - Попробуйте `0` → должно быть сообщение об ошибке
   - Попробуйте `13` → должно быть сообщение об ошибке
   - Попробуйте `abc` → должно быть сообщение об ошибке
   - Введите корректное число: `11`

2. При вводе дня:
   - Попробуйте `abc` → ошибка + повторный ввод
   - Попробуйте `35` → ошибка + повторный ввод
   - Введите корректное: `15`

3. При выборе типа:
   - Попробуйте `5` → ошибка + повторный ввод
   - Введите корректное: `1`

### Ожидаемый результат:

```
❌ Номер месяца должен быть от 1 до 12
❌ Неверный день: 'abc'. Попробуйте еще раз
❌ День должен быть от 1 до 31
❌ Неверный выбор: 5. Введите 1, 2 или 3
```

### ✅ Проверить:

- [ ] Ошибки не приводят к выходу из программы
- [ ] Возможность повторного ввода
- [ ] Информативные сообщения об ошибках
- [ ] Никаких traceback'ов при обычных ошибках ввода
